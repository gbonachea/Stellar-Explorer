# Marcas comerciales — Stellar Explorer

**Stellar Explorer** es un gestor de archivos de código abierto para Linux.

Este documento establece el uso permitido de las marcas relacionadas con el proyecto.

## Marcas

| Marca | Uso |
|---|---|
| **Stellar Explorer** | Nombre oficial del proyecto y la aplicación |
| **StellarExplorer** | Identificador en código, binario, .desktop, nombres de archivo |
| **Logo de Stellar Explorer** | Icono oficial de la aplicación |

## Uso permitido

Puedes usar las marcas "Stellar Explorer" y su logotipo para:

1. Referirte al proyecto oficial sin modificaciones
2. Distribuir copias sin modificar del binario o código fuente
3. Usar en capturas de pantalla, reseñas o artículos sobre el proyecto
4. Enlazar al repositorio oficial del proyecto

## Uso restringido

No está permitido:

1. Usar las marcas para promocionar productos o servicios no relacionados
2. Modificar el logotipo y redistribuirlo como oficial
3. Registrar las marcas como propias en ningún país
4. Usar el nombre para proyectos derivados que no sean claramente distintos

## Proyectos derivados

Si modificas Stellar Explorer y lo redistribuyes:

- Debes dejar claro que no es el proyecto oficial
- No debes usar el nombre "Stellar Explorer" como nombre principal de tu distribución
- Puedes indicar "Basado en Stellar Explorer" o "Fork de Stellar Explorer"

## Contacto

Para solicitar usos no contemplados aquí, abre un issue en el repositorio oficial del proyecto.
